# Дорожная карта — Poshat Launcher

## История проекта

- **6 месяцев**: Electron-версия (полный цикл разработки)
- **~1 неделя**: порт на Tauri + Rust (UI перенесён как есть, бэкенд переписан)
- **~1 месяц**: доработка фич, багфиксы, подготовка к релизу

## Текущий статус

Функциональный лаунчер, готовый к релизу как v3.0.0:
- Установка/запуск Minecraft (vanilla + Fabric/Quilt/Forge/NeoForge)
- Каталог Modrinth (моды, шейдеры, ресурспаки, датапаки)
- Ely.by авторизация (полный Yggdrasil + authlib-injector)
- Офлайн аккаунты
- Импорт/экспорт .mrpack
- Ярлыки на рабочий стол (Win + Linux)
- 6 тем, онбординг, анимации
- Автообновление
