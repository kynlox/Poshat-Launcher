# История изменений — Poshat Launcher

Все заметные изменения в проекте.

---

## [Не выпущено]

### Добавлено
- Автообновление через tauri-plugin-updater
- Onboarding-тур для новых пользователей
- Ярлыки на рабочий стол (Windows .lnk + Linux .desktop)
- Экспорт/импорт сборок (.mrpack)
- Видео-обложки для инстансов
- 6 тем оформления (dark, midnight, emerald, sunset, rose, light)
- Anti-debug защита в release-сборках
- Каталог Modrinth (моды, шейдеры, ресурспаки, датапаки)
- Ely.by авторизация (полный Yggdrasil + authlib-injector)
- Офлайн аккаунты с MD5 UUID
- Импорт/экспорт .mrpack
- Дублирование инстансов
- Пиннинг инстансов в сайдбаре
- Расчёт дискового размера инстансов
- Кастомные JVM-аргументы (GC тип, доп. аргументы)
- Размер окна Minecraft при запуске

### Изменено
- Полный порт с Electron на Tauri + Rust
- Установка Minecraft через lyceris (вместо ручной реализации)
- Кэширование Mojang manifest с 2-уровневой стратегией (память + файл)
- HTTP клиент с retry и зеркалами
- JSON store совместим с electron-store

### Исправлено
- Атомарная запись файлов (temp → rename)
- Path traversal защита для всех файловых операций
- Восстановление после битого store.json
- Дедупликация сетевых запросов к Mojang API
