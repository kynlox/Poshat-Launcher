# Чеклист релиза — Poshat Launcher

Перед каждым релизом проходить этот чеклист.

---

## v3.0.0 (текущий релиз)

### Критично

- [ ] `npm run tauri build` проходит без ошибок
- [ ] Установщик работает: установка → обновление → удаление → повторная установка
- [ ] Первый запуск: онбординг → выбор версии → запуск
- [ ] Офлайн аккаунт: создание → вход → запуск игры
- [ ] Ely.by аккаунт: вход → токен → запуск с authlib-injector
- [ ] Инстансы: создание → редактирование → удаление → дублирование
- [ ] Загрузчики: vanilla → Fabric → Forge → Quilt → NeoForge
- [ ] Моды: поиск → установка → обновление → удаление
- [ ] Ярлыки: создание → запуск через ярлык
- [ ] Экспорт/импорт .mrpack
- [ ] Автообновление лаунчера
- [ ] Маленькие экраны (800x600)

### Упаковка

- [ ] README.md написан
- [ ] LICENSE добавлен
- [ ] Описание в package.json, Cargo.toml, tauri.conf.json
- [ ] Скриншоты (3-5 штук)
- [ ] GitHub Releases: MSI + AppImage
- [ ] Обфускация JS убрана или объяснена

### Безопасность

- [ ] Токены не в открытом JSON (или описано почему)
- [ ] CSP включён (или объяснено почему нет)
- [ ] Нет лишних Tauri capabilities
- [ ] Build проверен через VirusTotal/Defender

### Качество

- [ ] Нет крашей при запуске
- [ ] Нет зависаний при загрузке модов
- [ ] Логи ошибок понятны пользователю
- [ ] Работает без интернета (кэш, уже установленные инстансы)

---

## Процесс релиза

1. Закрыть все пункты "критично"
2. Закрыть максимум пунктов "упаковка"
3. Проверить "безопасность" и "качество"
4. Собрать релиз: `npm run tauri build`
5. Загрузить на GitHub Releases
6. Обновить latest.json для автообновления
7. Опубликовать в сообществах (Discord, Telegram, форумы)
