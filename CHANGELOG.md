# Changelog

## [0.1.2] — 2026-07-24

Первый публичный релиз (закрытый исходный код).

### Added
- Автономные инстансы Minecraft
- Установка через lyceris (клиент, библиотеки, ассеты, нативы)
- Поддержка Fabric, Forge, NeoForge, Quilt, Vanilla
- Каталог модов/шейдеров/ресурспаков (Modrinth API)
- Мультиаккаунт (оффлайн + Ely.by)
- Экспорт/импорт сборок (.mrpack)
- Ярлыки на рабочем столе (Windows .lnk, Linux .desktop)
- Видео-обложки инстансов
- Автообновление (Tauri updater)
- Анти-отладка (Windows release)
- Обфускация JS-бандла (production)
- Кэш окна между сессиями
- Оффлайн-режим (ограниченный)

### Fixed
- CSP политика (был null)
- Dialog plugin подключен
- Удалены моковые данные
- Graceful degradation хуков при недоступности API
- Типы и валидация input'ов
