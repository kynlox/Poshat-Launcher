# Вклад в Poshat Launcher

Спасибо за интерес к проекту! Сейчас исходный код закрыт, но ты можешь помочь другими способами:

## Как помочь

### Сообщить об ошибке
1. Перейди в [Issues](https://github.com/docilan/Poshat-Launcher/issues)
2. Нажми "New Issue"
3. Выбери шаблон "Bug Report"
4. Опиши проблему максимально подробно

### Предложить идею
1. Перейди в [Issues](https://github.com/docilan/Poshat-Launcher/issues)
2. Нажми "New Issue"
3. Выбери шаблон "Feature Request"
4. Опиши свою идею

### Помочь с тестированием
- Скачай последнюю версию из [Releases](https://github.com/docilan/Poshat-Launcher/releases)
- Попробуй разные функции
- Сообщи о любых проблемах через Issues

### Поддержать проект
- Поставь ⭐ звёздочку репозиторию
- Расскажи друзьям о лаунчере
- Подпишись на Telegram-канал для обновлений

## Вопросы?

Если у тебя есть вопросы, напиши в [Issues](https://github.com/docilan/Poshat-Launcher/issues) с меткой `question`.
