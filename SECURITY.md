# Политика безопасности

## Сообщения об уязвимостях

Если ты нашёл уязвимость в Poshat Launcher, пожалуйста, **не публикуй детали в открытом Issue**.

Вместо этого:
1. Создай Issue с пометкой `security`
2. Опиши уязвимость максимально подробно
3. Укажи_steps для воспроизведения

Мы рассмотрим сообщение в приоритетном порядке и ответим в течение 48 часов.

## Что мы гарантируем

- Не запрашиваем и не храним пароль от Mojang/Microsoft аккаунта
- Обмен данными идёт напрямую с официальным Modrinth API
- Установочный пакет защищён от подмены
