## Возможности

- **⚡ Быстро и легко** — нативная сборка на Rust, запуск за доли секунды, минимум памяти
- **🗂️ Сборки** — полная изоляция инстансов: у каждой свои моды, конфиги и сохранения
- **🧩 Каталог Modrinth** — моды, шейдеры и ресурспаки прямо в лаунчере, без браузера
- **🔄 .mrpack** — экспорт и импорт сборок, совместимо с Modrinth App и Prism Launcher
- **👥 Аккаунты** — оффлайн, Ely.by и Microsoft (только с лицензией), переключение в один клик
- **🔗 Обложки и ярлыки** — иконка и ярлык на рабочем столе для каждой сборки
- **⚡ Автообновление** — новые версии приходят сами, каждый релиз подписан

Подробнее — в [Wiki](https://github.com/kynlox/Poshat-Launcher/wiki).
